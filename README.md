## 🛠️ HƯỚNG DẪN CÀI ĐẶT CHO NGƯỜI MỚI

1. Tải file **[OMNEI-Pro-v5.0-Commercial.zip](https://github.com/vuthedan168-oss/omnei-pro/raw/main/OMNEI-Pro-v5.0-Commercial.zip)** về máy tính.
2. Chuột phải vào file zip vừa tải -> Chọn **Extract All... (Giải nén)** ra một thư mục.
3. Mở trình duyệt Chrome, Cốc Cốc, Edge hoặc Brave.
4. Gõ vào thanh địa chỉ: `chrome://extensions/` rồi nhấn Enter.
5. Gạt bật công tắc **"Chế độ dành cho nhà phát triển" (Developer mode)** ở góc trên bên phải.
6. Bấm nút **"Tải tiện ích đã giải nén" (Load unpacked)** ở góc trên bên trái -> Chọn thư mục bạn vừa giải nén.
7. Bấm vào biểu tượng Mảnh ghép ở góc trên trình duyệt -> **Ghim OMNEI Pro** lên thanh tiện ích để bắt đầu sử dụng!

## 🌟 TÍNH NĂNG NỔI BẬT

- **Chuyển đổi phiên 1-click**: Đăng nhập cùng lúc hàng chục tài khoản Facebook, TikTok, Shopee, X mà không bị đá văng (log out) tài khoản cũ.
- **Antidetect Shield Mini**:
  - *Canvas Fingerprint Randomizer*: Trộn vi nhiễu vào hình ảnh Canvas để mỗi nick có vân tay riêng.
  - *WebGL Hardware Masking*: Giả lập card đồ họa rời chuẩn quốc tế.
  - *AudioContext Micro-Jitter*: Chống nhận diện sóng âm phần cứng.
  - *WebRTC Anti-Leak Shield*: Chống lộ địa chỉ IP thật của máy khi sử dụng Proxy.
- **Quản lý Proxy độc lập**: Gán Proxy HTTP/SOCKS5 riêng cho từng tài khoản, tự động đổi IP khi chuyển nick.
- **Check Live/Die hàng loạt**: Kiểm tra nhanh trạng thái nick sống/chết không tốn thời gian.
- **Bảo mật tuyệt đối**: Dữ liệu lưu trữ cục bộ trên máy tính của bạn, mã hóa AES-GCM, không gửi cookie lên bất kỳ máy chủ trung gian nào.
